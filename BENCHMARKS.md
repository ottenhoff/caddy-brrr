# Benchmark Notes

Run the full comparison with:

```sh
go test -run '^$' -bench=. -benchmem ./...
```

The benchmark matrix covers:

- payloads: HTML, JSON, JavaScript, CSS
- encoder paths: direct `NewEncoder` and full Caddy `encode.ServeHTTP`
- encoders: Caddy gzip, Caddy zstd, and `go-brrr` Brotli
- levels: gzip `1/5/9`, zstd `fastest/default/best`, Brotli `0/1/2/4/6/9/11`
- metrics: `ns/op`, `MB/s`, compression `ratio`, `B/op`, `allocs/op`
